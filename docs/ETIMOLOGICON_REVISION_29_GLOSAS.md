## Matices incorporados

- **ἀνά:** «hacia arriba, a lo largo de»; «de nuevo» es una posibilidad de composición, no una traducción universal.
- **ἐκ / ἐξ:** alomorfos de una misma preposición, diferenciados por el contexto fonético.
- **αὐτός:** la construcción con artículo determina el valor «el mismo»; sin él puede ser «él mismo» con sentido intensivo.
- **πράττω / πρᾶγμα:** verbo «hacer, actuar» frente a sustantivo «hecho, asunto».
- **γράφω / γράμμα:** «trazar, dibujar o escribir» frente a «letra, carácter escrito».
- **σοφός / σοφία:** adjetivo «sabio, hábil» frente a sustantivo «sabiduría, destreza».
- **λέγω / λόγος:** «decir, hablar» frente a «palabra, discurso, razón».
- **γλῶττα:** forma ática de γλῶσσα, «lengua» como órgano y como idioma.
- **ἄλγος:** dolor físico y también dolor anímico.
- **λάρυγξ:** confirmado mediante documentación académica histórica; distinguir de φάρυγξ y del uso anatómico moderno.

Cada entrada registra URL de evidencia y nota de revisión; las cuatro referencias no equivalentes a un artículo lexicográfico individual están marcadas como tales. Las notas de las fuentes se parafrasean para uso didáctico. Se conserva el registro previo de todas las traducciones para detectar cambios.
